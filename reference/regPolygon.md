# Regular Polygon Geometry

Create a regular polygon.

## Usage

``` r
regPolygon(x = 0, y = 0, radius = 1, nVertices = 6, startAngle = 0)
```

## Arguments

- x, y:

  centre coordinates.

- radius:

  circumradius.

- nVertices:

  number of vertices.

- startAngle:

  staring angle in radians.

## Value

An object inheriting from class `"regPolygonGeometry"`.
